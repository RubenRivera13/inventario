# Proyecto de inventario Serverless con Supabase

Objetivo del proyecto

Construir un backend serverless utilizando Supabase para administrar:

-Categorías
-Proveedores
-Productos
-Movimiento de inventarios
-Autenticación de usuario
-Seguridad mediante Row Level Security
-Funciones y triggres en PostgreSQL
-Realtime subscription
-Storage de imágenes

# Tecnologias utilizadas

-Supabase
-PostgreSQL 15
-Supabase Auth
-Supabase Realtime
-Supabase Storage
-HTML5
-JavaScript
-SQL/PLgSQL
